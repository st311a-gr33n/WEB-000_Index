Git: Remotes & Branches

REF-001 LOG // REF / REFERENCES REFERENCE RECORD PUBLISHED

A practical reference for the two connected parts of everyday Git work: managing remote repositories and operating on branches. Commands are kept in their plain form; each entry states what the operation does and where it belongs in the workflow.

Git Remotes

Add a remote

Attaches a new remote name to a repository URL. The name is the short handle used by every later fetch, push, and pull against that repository.

Syntax
git remote add <name> <url>
Example
git remote add origin git@github.com:username/repository.git

Change a remote URL

Re-points an existing remote name at a new URL — after a repository rename, an account transfer, or a switch between SSH and HTTPS. History and branch configuration stay attached to the name.

Syntax
git remote set-url <remote name> <new-url>
Example
git remote set-url origin git@github.com:username/repository.git

List remotes

Shows every remote configured for the repository. -v adds the fetch and push URLs, so mismatches between them are visible immediately.

git remote -v

Remove a remote

Detaches a remote name from the repository. Local branches and history are untouched; only the named connection is deleted.

git remote remove <name>

Git Branches

Create and switch to a new branch

Creates a branch and moves HEAD onto it in one step. git switch -c is the current form; git checkout -b is the older equivalent. Moving to an existing branch uses either command without the flag.

git switch -c <new-branch-name>
# or
git checkout -b <new-branch-name>
# switch to existing branch
git checkout <branch-name>

Create a branch without switching

Leaves HEAD where it is and only records the new branch pointer — useful when preparing a branch for later without leaving the current work.

git branch <new-branch-name>

Push a branch to remote

Publishes the branch to the remote and sets its upstream with -u, so later git push and git pull on that branch need no arguments.

git push -u origin <new-branch-name>

Merge

Integrates a branch into the branch you are on. Check out the target branch first — main in the usual case — then merge the feature branch into it.

git checkout main
git merge <branch-name>

Delete a branch

Removes a local branch after its work has been integrated. Deleting keeps the repository list clean; the commits remain reachable through the branch they were merged into.

git branch -d <branch-name>
